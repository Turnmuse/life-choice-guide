## 三、关键术语速查

- **人选 / 祸 / 天选**：人选=你当下的选择；祸=代价（不是灾难）；天选=结果（由你之外的一切选择交织而成）。出处：`renxuan-tianxuan-lun.md` 序。
- **没有运气，只有选择**：所谓运气是看不见的选择叠加。出处：`renxuan-tianxuan-lun.md` 序。
- **破画原理**：画中人不能撕毁画卷；观测本身是变量的一部分——未来不可预测也不可干涉。出处：`renxuan-tianxuan-lun.md` 序。
- **贪梦（贪欲/贪婪）/ 恐惧**：想得到（伸手）vs 怕失去（缩手）；一切波澜的源头。出处：`renxuan-tianxuan-lun.md` 序、`renxuan-tianxuan-lun.md` 第一章·河流世界。
- **大石头 / 小碎石**：贪梦像大石头（显眼、起浪），恐惧像小碎石（细碎、会藏、堵河）。出处：`renxuan-tianxuan-lun.md` 第三章·硬币世界。
- **堰塞湖**：恐惧小石头堆堵河道 → 拖延（流不动）、自洽（给不动找解释）、麻木（忘了想去哪里）。出处：`renxuan-tianxuan-lun.md` 第三章·硬币世界。
- **波纹 / 石头 / 河形**：借口理由自洽=水面波纹；贪梦恐惧=河底石头；先看清自己是哪种河（宽浅窄深/流量流速）。出处：`renxuan-tianxuan-lun.md` 第一章·河流世界。
- **捞石头 / 潜水 / 改河道**：三种看河底的办法——最推荐捞石头（最慢最安全最小代价）。出处：`renxuan-tianxuan-lun.md` 第二章·人之路。
- **道痕**：每天从河里捞一块石头的记录，7 层模板见 `renxuan-tianxuan-lun.md` 第二章·人之路。出处：`renxuan-tianxuan-lun.md` 第二章·人之路。
- **写给别人看会变形**：只要预设读者，内容就开始隐藏/强调/编排；道痕首要对己真实。出处：`renxuan-tianxuan-lun.md` 第二章·人之路。
- **天权**：贪婪与恐惧之间那座还没断掉的桥（能来回走、能调）。出处：`renxuan-tianxuan-lun.md` 序、`renxuan-tianxuan-lun.md` 第五章·天权是如何被发现的。
- **五种境界**：迷失（天权崩塌）/ 求福（天权摇摆）/ 见机（天权可视）/ 持衡（天权可控）/ 两忘（天权消散）——即时状态，非永久人格。出处：`renxuan-tianxuan-lun.md` 序。
- **桥断 / 只剩一边**：只剩自信/自卑/贪婪/恐惧都走向极端；解释变成牢笼。出处：`renxuan-tianxuan-lun.md` 第六章·天权的裂痕。
- **画中人思维**：找一个让自己舒服的解释（"她不就是睡导演吗"），把世界解释简单以麻痹自己，却看不见真正的因果。出处：`renxuan-tianxuan-lun.md` 第六章·天权的裂痕。
- **天选六段**：起始（止急）/ 发展（止扩）/ 对抗（止乱）/ 稳定（止逸）/ 衰退（止松）/ 崩溃（止逆）。出处：`renxuan-tianxuan-lun.md` 第四章·破执见势定心。
- **人选三剑**：破执（缩小自己放大世界）/ 见势（看清自己在哪一段）/ 定心（止急止飘止妄想）。出处：`renxuan-tianxuan-lun.md` 第四章·破执见势定心。
- **短期欲望 / 长期欲望**：短期来自身体本能、满足就退；长期欲望本质是恐惧（怕以后没有），让人追求"保障"。出处：`renxuan-tianxuan-lun.md` 第五章·天权是如何被发现的。
- **心中形成的人间**：人活着的世界是外物经经验/记忆/欲望/恐惧后在心里形成的世界。出处：`renxuan-tianxuan-lun.md` 第七章·自成人间。
- **顿悟只是回声**：人靠"一次明白后无数次做不到、又无数次看见自己做不到"慢慢改变。出处：`renxuan-tianxuan-lun.md` 第七章·自成人间。
- **火与雪的两种变好**：雪里的"暖"=失去知觉（危险），火边的"暖"=恢复知觉（刺但真实）——变好要看是更有感觉还是更没感觉。出处：`renxuan-tianxuan-lun.md` 第四章·破执见势定心。
