# 决定校验清单

## 职责与边界

**这份文档负责**：当用户带着一个已经做出的决定来求验证时（SKILL.md 第 0 步判定为"决定"），提供逐条校验的标准清单。

**不负责（边界）**：

1. 本文只做**校验**，不做选题——决定已经做出，本文的任务是找出它没算到的风险，不是重新替他选。
2. 校验不通过的条目标注为风险即可，**不等于否决整个决定**；是否构成"明显大坑"、是否启用第 5 步骂醒，以 SKILL.md 第 0 步为准。
3. 本文的输出必须展示校验过程（每条过没过、依据是什么），不许只给结论。
4. 各条目背后的完整方法论见 `books/` 对应书籍；本文只保留校验动作。

## 使用方法

- 逐条过一遍，每条给出三态之一：**通过 / 有风险（说明依据）/ 无法判断（缺什么信息、怎么补）**。
- 全部"无法判断"本身也是一个结论：这个决定还没有到能做的时候，先补信息。
- 用户没说的信息不许替他假设——标"无法判断"比猜一个"通过"负责任得多。

## 校验清单

### 1. 步伐与节奏：是否小步可验证

- 校验点：这个决定的第一步是否足够小、足够快、能立刻产生真实反馈？还是一上来就要求长时间、大投入、全情投入？
- 不合格信号：起步就是高强度、长周期、依赖意志力硬撑的方案。
- 合格信号：存在一个几乎不可能失败的最小起步版本，且反馈周期短。
- 方法出处：`books/yuanzi-xiguan.md`。

### 2. 人与事的匹配：热爱、擅长、特性、趋势

- 校验点（四个筛子，缺一就要说明理由）：
  - **热爱**：这件事里有没有他不觉得是负担、甚至觉得像玩的部分？
  - **擅长**：是否主要用他的优势，而不是主要用短板硬扛？
  - **特性**：这件事对人的要求，和他的性格特质是顺的还是拧的？
  - **趋势**：方向与社会发展趋势是同向还是逆向？
- 趋势校验的附加规则：如果赌的是**未来的趋势**，必须额外说明——周期长、中途无反馈的时间多，需要相应的资金、耐心与阶段性验证安排，不能只画远方的饼。
- 方法出处：`books/nawaer-baodian.md`。

### 3. 目标距离：远大目标是否被拉回当下

- 校验点：如果定的是很大、很远的目标——当下要验证的是什么？有没有把"无法验证的远大目标"拆成"本周、本月能被现实检验的小问题"？
- 不合格信号：叙述里只有远方，没有下一步；用目标的宏大来回避眼前的验证。
- 合格信号：远大目标被翻译成了当下可验证的最小命题，且验证失败时知道调整什么。

### 4. 可逆性与下行风险

- 校验点：这个决定可逆吗？最坏结果是什么、谁承担、承担得起吗？输了之后还有没有下一次的筹码？
- 不合格信号：不可逆 + 押上输不起的东西（二者同时成立即触红线，直接按 SKILL.md 第 0 步大坑处理）。
- 方法出处：`books/qiongchali-baodian.md`。

### 5. 成本与时间账

- 校验点：这个决定的消耗速度是多少？他能撑多久？时间站在他这边还是对面？
- 不合格信号：只算了"做成了得到什么"，没算"撑下去每天要付什么"。

### 6. 反馈机制：有没有真实、及时的反馈

- 校验点：这条路有没有清晰的反馈信号，多久一次？他凭什么知道自己走在对的路上？
- 不合格信号：反馈周期以年计，或反馈完全不可观测——那意味着错误也要以年计才能发现。
- 方法出处：`books/yuanzi-xiguan.md`（潜能蓄积期与反馈）、`references/xianshi-jiaoyan.md` 行动镜。

### 7. 动机方向：是在走向什么，还是在逃离什么

- 校验点：这个决定的动力是"想要"还是"想躲"？如果拿掉他此刻想逃离的东西，这个决定还成立吗？
- 不合格信号：决定的对象换来换去都可以，只要能离开现状——那是逃避穿了选择的衣服。
- 这是最重要的单条校验之一，与 SKILL.md 第 0 步的"逃避/沉浸"检验直接衔接。

### 8. 沉没成本剥离

- 校验点：把过去已经投入的一切（时间、钱、感情、面子）全部假设为零——如果今天从零开始，他还会做同样的决定吗？
- 不合格信号：理由里出现"都到这一步了""已经投入这么多"。已经付出的不是理由，未来能得到的才是。
- 方法出处：`books/qiongchali-baodian.md`（避免不一致性、损失厌恶）。

### 9. 依赖与单点风险

- 校验点：这个决定的成功是否完全押在某一个人、平台、公司或外部条件的配合上？那个单点变脸了，他还有什么？
- 合格信号：存在备选空间，或关键依赖是可控、可迁移的。

### 10. 积累性：是在滚雪球还是每年清零

- 校验点：这件事的能力、资源、声誉能否积累？三年后回头看，这三年是滚大了什么，还是原地消耗？
- 不合格信号：每年都要从零开始，且积累物不可迁移。
- 方法出处：`books/nawaer-baodian.md`（复利）。

### 11. 阶段匹配

- 校验点：这个决定与他所处的阶段（起步/发展/对抗/稳定/衰退/崩溃）匹配吗？同一动作在不同阶段对错相反。
- 不合格信号：在需要收敛的阶段扩张，在需要行动的阶段继续准备。
- 判定方法见 `books/renxuan-tianxuan-lun.md` 第四章。

### 12. 信息完备度：这个决定到了"能定"的时候吗

- 校验点：以上各条里有多少标了"无法判断"？关键未知项是否有具体的验证动作和时间点？
- 不合格信号：在关键信息缺失的情况下，用决心的强度代替信息的厚度。

## 输出格式要求

校验结果的呈现顺序：

1. 先给总判定（方向成立 / 方向成立但有明显风险 / 存在大坑）；
2. 再逐条给校验过程，三态分明；
3. 有风险和无法判断的条目，各给一句具体的补救动作；
4. 若判定为大坑，按 SKILL.md 第 0 步启用第 5 步。
