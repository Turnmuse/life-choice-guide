# 决定校验清单（决定模式 + 刺猬三环权威定义）

当 `SKILL.md` 第 0 步判定为“决定”时使用本清单；涉及钱或长期方向投入的**提问与决定**，均须按本文「刺猬三环」标准给出三环结论。

---

## 一、扫描与输出聚焦纪律（防机械审计）

- **两层结构**：**通用校验**（每个决定后台全量扫描）+ **专项校验·刺猬三环**（涉及钱或长期方向投入时触发）。
- **聚焦呈现，拒绝流水账**：
  - 后台用「评估手法 + 12 项通用校验」完整扫描一遍，每项标三态：`✅ 成立` / `⚠️ 有风险` / `❓ 无法判断`（主干踩红线标 `❌ 不成立`）。
  - **输出时突出致命项**：将所有 `❌ 不成立`、`⚠️ 有风险`、`❓ 无法判断` 逐条展开说清依据与补救动作；所有 `✅ 成立` 项合并为 1–2 行或紧凑表格汇总，不铺张流水账。
  - 清单只是参照而非边界：若决定存在清单外的新维度风险，AI 必须补充并同等展示；用户未说的信息一律标 `❓ 无法判断`，不代为假设。

---

## 二、先跑一遍整体评估手法（源自 `books/duizhu.md`）

按相关性对**整个决定**跑一遍，再进入逐项打标（非量化局不硬凑百分比）：
1. **概率化**：把“能成”翻译成大致胜率与依据，反问“你愿意为这个判断押上什么？”
2. **事前验尸**：假设一年后已失败，写出前三个最可能死因；反向核对“若成功，最关键做对了什么、用户现在具不具备？”
3. **二阶后果**：每条路至少追问两层“然后会怎样”。
4. **非对称期望值**：“赢了小赚、输了清零”的局直接亮红灯，无论胜率多高。
5. **10/10/10**：10 天、10 个月、10 年后分别怎么看？三者打架处即情绪劫持点。
6. **结果与决策分离**：只用做决定当刻可得的信息评估，不用事后结果倒推。

## 三、通用校验 12 项（后台全扫，输出聚焦风险项）

| # | 校验维度 | 核心拷问 | 不合格 / 风险信号 |
|---|---|---|---|
| 1 | **动机方向**（最重要） | 动力是“想要”还是“想躲”？拿掉想逃离的现状，决定还成立吗？ | 对象可随意替换，只要能离开现状（逃避穿了选择的衣服） |
| 2 | **步伐与节奏** | 第一步是否足够小、快、能立刻出真实反馈？ | 一上来就高强度、长周期、全靠意志力硬撑 |
| 3 | **目标距离** | 远大目标是否拆解成了本周/本月可被现实检验的小问题？ | 只有远方没有下一步，用宏大目标回避眼前验证 |
| 4 | **可逆性与下行** | 最坏结果是什么、谁承担、输了还有没有下次筹码？ | 不可逆 + 押上输不起的筹码（直接触发第 0 步大坑） |
| 5 | **成本与时间账** | 消耗速度多快、能撑多久、时间站在哪一边？ | 只算做成的收益，不算撑下去每天的失血 |
| 6 | **反馈机制** | 有没有清晰及时的外部反馈信号？多久一次？ | 反馈周期以年计或完全不可观测 |
| 7 | **沉没成本剥离** | 假设过去投入（时间/钱/感情/面子）全部清零，今天还会选吗？ | 把已经付出的当成继续的理由本身 |
| 8 | **特性匹配** | 长期要求与用户真实性格/禀赋是顺的还是拧的？ | 决定成立的前提是“变成另一个人” |
| 9 | **单点依赖风险** | 成功是否完全押在某一个人、平台或单一外部条件上？ | 单点变脸即彻底归零，无备选与迁移空间 |
| 10 | **积累性（复利）** | 三年后能力、资源、声誉是滚大了，还是每年清零？ | 原地消耗，积累物不可迁移 |
| 11 | **阶段匹配** | 是否契合当前阶段（见 `daohang7bu.md` 天选六段）？是否恰好在做该段最该止的事？ | 起步急、发展扩、对抗乱、稳定逸、衰退松、崩溃逆（证据不足不定阶段） |
| 12 | **信息完备度** | 关键未知项是否有具体验证动作与时间点？ | 在信息真空里用“决心的强度”替代“信息的厚度” |

## 四、专项校验：刺猬三环（唯一权威定义）

> 出处：《从优秀到卓越》个人化转译（完整方法见 `books/cong-youxiu-dao-zhuoyue.md`）。
> **触发条件**：涉及钱、变现、长期方向投入 → **必查**；表面无关钱但经衡量经济是底层关键变量 → 同样启用。

### 三环与证据三态

每环必须单独标注 **`✅ 成立` / `❓ 未验证` / `❌ 反向证据`**：

1. **市场要什么（市场环）**：
   - 需求等级必须是**痛点**（不解决就难受），不是痒点（有更好、没有也行）。
   - **唯一硬标准**：有没有人为**用户提供的这类价值**付过真金白银。“我觉得会有人需要”不具证据资格；领域有需求 ≠ 用户的价值有人买单。趋势顺逆并入本环（赌远期趋势须明确周期、资金与阶段验证）。
   - 赛道结构拆解（饱和度、壁垒、变现链路等）见 `shichang-chaijie.md`。
2. **用户有什么（能力环）**：
   - 可核实的技能、经验、洞察、人脉与过往结果；是否在用核心优势打，而非短板硬扛。
3. **用户能持续做什么（热情/耐力环）**：
   - 在没有掌声、没有正反馈的几个月里，是否仍有持续投入的行为证据。

**反向证据铁律**：若出现“验证过没人买 / 做过且失败 / 行为上明显耗不动”，必须标为 **`❌ 反向证据（已证伪待推翻）`**，严禁混同为“未验证”：
- 市场环反向证据只能由**新的真实付费**推翻（调研、访谈、再想想都不算）；
- 能力环由**新的真实结果**推翻；热情环由**新的持续行为**推翻。

### 缺环偏差定位

- 能力 + 热情，缺市场 = **能力自嗨**（做得很好，没人买单）
- 市场 + 热情，缺能力 = **市场错配**（看得见蛋糕，吃不进嘴）
- 能力 + 市场，缺热情 = **不可持续**（能赚钱，但迟早被自己耗死）

## 五、决定模式输出顺序（置于 `✅ 综合建议 · 建议分析` 内）

1. **先亮档位与依据**：按排除法给出 `存在大坑` / `方向有明显风险` / `方向成立` 及判定理由；
2. **展开关键校验**：重点剖析所有 `❌ / ⚠️ / ❓` 项，简要汇总 `✅` 项；触发刺猬三环时单段列出三环证据等级与偏差类型；
3. **必给上调路径**：二、三档必须明确缺什么证据、先做什么验证动作、满足什么条件可升入第一档（只否不建是失职）；
4. **命中大坑**：按 `SKILL.md` 第 0 步启用第 5 步当头棒喝。
