# 决定校验清单

## 职责与边界

**这份文档负责**：当用户带着一个已经做出的决定来求验证时（SKILL.md 第 0 步判定为"决定"），提供校验的标准与结构。

**不负责（边界）**：

1. 本文只做**校验**，不做选题——决定已经做出，本文的任务是找出它没算到的风险，不是重新替他选。
2. 校验不通过的条目标注为风险即可，**不等于否决整个决定**；是否构成"明显大坑"、是否启用第 5 步当头棒喝，以 SKILL.md 第 0 步为准。
3. 校验必须展示过程（每条过没过、依据是什么），不许只给结论。
4. 各条目背后的完整方法论见 `books/` 对应书籍；本文只保留校验动作。

## 校验结构：两层

校验分两层，别混用：

- **通用校验**：每一个决定都过。它回答"这个决定本身成立吗"。
- **专项校验**：按触发条件启用。它回答"这一类决定特有的死法是什么"。目前只有一个专项模块：刺猬三环——涉及钱或长期方向投入时触发。

分层的原因：如果所有校验都压给所有决定，涉及钱的决定查得不够深，不涉及钱的决定被无关条款误伤。

## 使用方法

- 清单是参照，不是边界。逐条过一遍，每条给出三态之一：**通过 / 有风险（说明依据）/ 无法判断（缺什么信息、怎么补）**。
- 清单没覆盖到的维度，由 AI 根据决定的具体情况自行补充校验；**不因清单没写就视为不合格，也不把决定硬往清单条目上套**。自行补充的校验项，在输出中与清单条目同等展示。
- 全部"无法判断"本身也是一个结论：这个决定还没有到能做的时候，先补信息。
- 用户没说的信息不许替他假设——标"无法判断"比猜一个"通过"负责任得多。

## 评估手法（先对整个决定跑一遍，再逐条打三态）

清单回答"查什么"，手法回答"怎么查"。六个动作先对**整个决定**跑一遍，逐条打三态时按需回看——不机械地对每条校验各跑六遍。按相关性选用：概率化与期望值偏钱类或量级大的决定；亲密关系、心理类决定能量化则量化，**不硬凑百分比**。方法出处：`books/duizhu.md`。

1. **概率化**：把这个决定的"能成"翻译成百分比，并列出依据。附一句问用户："你愿意为这个判断押上什么？"——答不出依据的信心，不算信心。
2. **事前验尸**：假设一年后这个决定已经失败了，写讣告：它死于什么？前三个死因就是最重要的风险来源。配套反向：假设成功了，最关键做对了什么？那个因素他具备吗？
3. **二阶后果**：每条路径追问"然后会怎样"，至少推到第二层。
4. **期望值与非对称**：上行多大、下行多大？"赢了小赚、输了清零"的局直接亮红灯，无论成功概率多高。
5. **10/10/10**：10 天后、10 个月后、10 年后分别怎么看这个决定？三个答案打架的地方，就是情绪劫持判断的地方。
6. **结果与决策分离**：只用做决定那一刻可得的信息评估，不用后来的结果倒推——无论结果好坏。

## 通用校验（每个决定都过）

### 1. 动机方向：是在走向什么，还是在逃离什么

- 校验点：这个决定的动力是"想要"还是"想躲"？如果拿掉他此刻想逃离的东西，这个决定还成立吗？
- 不合格信号：决定的对象换来换去都可以，只要能离开现状——那是逃避穿了选择的衣服。
- 这是最重要的单条校验，与 SKILL.md 第 0 步的"逃避/沉浸"检验直接衔接。

### 2. 步伐与节奏：是否小步可验证

- 校验点：第一步是否足够小、足够快、能立刻产生真实反馈？还是一上来就要求长时间、大投入、全情投入？
- 不合格信号：起步就是高强度、长周期、依赖意志力硬撑的方案。
- 合格信号：存在一个几乎不可能失败的最小起步版本，且反馈周期短。
- 方法出处：`books/yuanzi-xiguan.md`。

### 3. 目标距离：远大目标是否被拉回当下

- 校验点：如果定的是很大、很远的目标——当下要验证的是什么？有没有把"无法验证的远大目标"拆成本周、本月能被现实检验的小问题？
- 不合格信号：叙述里只有远方，没有下一步；用目标的宏大来回避眼前的验证。

### 4. 可逆性与下行风险

- 校验点：这个决定可逆吗？最坏结果是什么、谁承担、承担得起吗？输了之后还有没有下一次的筹码？
- 不合格信号：不可逆 + 押上输不起的东西（二者同时成立即触红线，直接按 SKILL.md 第 0 步大坑处理）。
- 方法出处：`books/qiongchali-baodian.md`。

### 5. 成本与时间账

- 校验点：这个决定的消耗速度是多少？他能撑多久？时间站在他这边还是对面？
- 不合格信号：只算了"做成了得到什么"，没算"撑下去每天要付什么"。

### 6. 反馈机制：有没有真实、及时的反馈

- 校验点：这条路有没有清晰的反馈信号，多久一次？他凭什么知道自己走在对的路上？
- 不合格信号：反馈周期以年计，或反馈完全不可观测——那意味着错误也要以年计才能发现。
- 方法出处：`books/yuanzi-xiguan.md`、`references/xianshi-jiaoyan.md` 行动镜。

### 7. 沉没成本剥离

- 校验点：把过去已经投入的一切（时间、钱、感情、面子）全部假设为零——如果今天从零开始，他还会做同样的决定吗？
- 不合格信号：把过去的投入当成继续的理由本身。提及投入不等于依赖它——判断标准只有一个：投入清零后，这个决定还站得住吗？已经付出的不是理由，未来能得到的才是。
- 方法出处：`books/qiongchali-baodian.md`。

### 8. 特性匹配

- 校验点：这件事长期对人的要求，和他的性格特质是顺的还是拧的？
- 不合格信号：决定成立的前提是他变成另一个人。

### 9. 依赖与单点风险

- 校验点：成功是否完全押在某一个人、平台、公司或外部条件的配合上？那个单点变脸了，用户还有什么？
- 合格信号：存在备选空间，或关键依赖可控、可迁移。

### 10. 积累性：是在滚雪球还是每年清零

- 校验点：这件事的能力、资源、声誉能否积累？三年后回头看，这三年是滚大了什么，还是原地消耗？
- 不合格信号：每年都要从零开始，且积累物不可迁移。
- 方法出处：`books/nawaer-baodian.md`（复利）。

### 11. 阶段匹配

- 校验点：这个决定与他所处的阶段（起步/发展/对抗/稳定/衰退/崩溃）匹配吗？同一动作在不同阶段对错相反。
- 不合格信号：在需要收敛的阶段扩张，在需要行动的阶段继续准备。
- 一并核对各段最该止的事——起步止急、发展止扩、对抗止乱、稳定止逸、衰退止松、崩溃止逆：这个决定是不是恰好在做该段最该止的事。
- 阶段由 AI 依事实推理判定，证据不足不定阶段；六段定义见 `books/renxuan-tianxuan-lun.md` 第四章。

### 12. 信息完备度：这个决定到了"能定"的时候吗

- 校验点：以上各条里有多少标了"无法判断"？关键未知项是否有具体的验证动作和时间点？
- 不合格信号：在关键信息缺失的情况下，用决心的强度代替信息的厚度。

## 专项校验：刺猬三环（涉及钱或长期方向投入时触发）

来自《从优秀到卓越》（柯林斯）的个人化转译，方法论详见 `books/cong-youxiu-dao-zhuoyue.md`。

**触发条件**：

- 决定涉及钱、变现，或要押上长期时间投入一个方向 → **必查**，且最终建议必须包含三环各自的证据等级。
- 不直接涉及钱的决定，由 AI 衡量钱在其中的真实权重：许多看似与钱无关的矛盾，底层仍是经济因素。若判断钱是关键变量，同样启用三环。

**三环**：

1. **市场要什么**：这个方向上，市场中用户的真实需求是什么？需求等级必须分清——**痒点（有更好，没有也行）不产生钱，痛点（不解决就难受）才产生钱**。验证标准只有一个：有没有人为同类价值付过真金白银，"我觉得会有人需要"这类感觉判断不算证据——它只是不享有证据资格，用户话里出现这句，不否定环里已有的付费事实。趋势顺逆并入本环：方向与社会发展趋势同向还是逆向；赌未来趋势必须额外说明周期长、中途反馈少，需要相应的资金、耐心与阶段性验证安排，不能只画远方的饼。注意区分两个层面：第 2 步的领域需求评估只说明"这个领域有人要东西"，是素材不是证据；市场环成立只看**用户这个价值**有没有人付钱——领域有需求 ≠ 用户的价值有人买。
2. **用户有什么**：用户的能力、积累、洞察、人脉里，什么是比别人强、甚至有潜质成为最优秀的？是否主要用优势，而不是用短板硬扛？
3. **用户能持续做什么**：这件事里有没有用户不觉得是负担、甚至觉得像玩的部分？在没有掌声、没有正反馈的几个月里，用户还愿不愿意继续做下去？

赛道级拆解（饱和度、壁垒、变现路径、持续性等维度与多赛道对比的输出格式）见 `shichang-chaijie.md`。它与市场环是两层：市场环判**成立与否**（证据三态），拆解维度判**结构优劣**（这个赛道好不好打）。

**每环单独给三态：成立 / 未验证 / 反向证据**（结论里逐环标注）：

- **成立**：有硬证据——市场环是付费证据，能力环是可核实的积累与结果，热情环是无掌声期仍持续的行为。
- **未验证**：无证据也无反证——补上验证动作即可。
- **反向证据**：验证过了没人买、做过且失败、行为上明显耗不动。**比缺失更重**，不许用"再验证一下"带过：市场环的反向证据只能由新的真实付费推翻，能力环由新的真实结果推翻，热情环由新的持续行为推翻。

**判定规则**：三环缺一，定位必偏——

- 有能力 + 有热情、没市场 = **能力自嗨**（做得很好，没人买单）；
- 有市场 + 有热情、没能力 = **市场错配**（看得见蛋糕，吃不进嘴）；
- 有能力 + 有市场、没热情 = **不可持续**（能赚钱，但迟早被自己耗死）。

环判"未验证"不等于否决，但必须说清：缺哪环、偏差类型是什么、用什么动作在多长时间内补上、补不上怎么办。环判"反向证据"必须把"已证伪待推翻"写在明处，不与"待验证"混同。

## 输出格式要求

校验结果放在「✅ 综合建议 · 建议分析」内呈现（SKILL.md 的四节结构不变），顺序：

1. 先给总判定，档位与 SKILL.md 第 0 步一致：**存在大坑 / 方向有明显风险 / 方向成立**（按排除法顺序判定：先查大坑，再查风险，最后才是成立）；
2. 再逐条给校验过程，三态分明；触发了刺猬三环的，三环结论单独成段列出；
3. 定为"存在大坑"或"方向有明显风险"时，必须同时给出上调档位的路径：缺什么证据、先做什么验证动作、满足什么条件即可进"方向成立"；
4. 若判定为大坑，按 SKILL.md 第 0 步启用第 5 步。
