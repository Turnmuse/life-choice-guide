# 七层自我剖析：执行指南与核心机制速查

> 方法源头：《人选天选论》（姜蓝 著）第二章·人之路（原文整理）+ 第三/四/六章核心机制精简版。
> 注意：本文件供 AI 内部理解使用；文中的“你”指用户，“我”指替用户写的第一人称；书内比喻（水面/波纹/石头/捞/桥）**严禁出现在面向用户的输出里**，一律翻译为大白话。

## 一、核心心理机制速查（无需每次通读 68KB 全书笔记）

1. **贪梦（大石头）vs. 恐惧（小碎石）**
   - 贪梦显眼、让人冲动伸手；恐惧细碎且极会伪装——它很少说“我害怕”，常说“再等等 / 还没准备好 / 我只是理性谨慎 / 现在不合适”。
   - **堰塞湖机制**：细碎的恐惧长期不看，会堵死行动力，表现为**拖延（流不动）、自洽（给不动找高级理由）、麻木（忘了本来想去哪）**。很多人的“迷茫”不是没目标，是被小恐惧堵死了。
   - **长期欲望的本质是恐惧**：对钱、保障、退路的执念，底层往往是“怕以后没有 / 怕失去”，剖析第 4 层时别误归为单纯贪心。
2. **解释会变成行动逻辑（画中人思维）**
   - 人天生会找“让自己舒服的解释”（如“别人成功全靠运气/资源”），最致命的是**今天用来安慰自己的借口，明天就会变成行动的错误指南针**。第 5 层（理由）的核心检验句：“这个解释到底是为了真相，还是为了保护自己？”
3. **天权之桥（单边失衡预警）**
   - 正常人既想要又害怕；当主症结只剩单边（只剩贪婪狂冲、或只剩恐惧一味后退），说明内心调节机制濒临断裂。第 7 层的最小动作本质是**把人拉回平衡**——狂冲时看见代价（止），退缩时看见想要（动）。
4. **天选六段与各段最该止的事**（依事实推理判定，证据不足不定阶段）
   | 阶段 | 核心特征 | 本段最该止的事 |
   |---|---|---|
   | **起步**（起始） | 刚入局、模糊、无反馈 | **止急**（别拿成熟期结果要求起步期） |
   | **发展** | 势头起来、反馈变正 | **止扩**（别飘、别盲目加杠杆扩张） |
   | **对抗** | 竞争白热化、摩擦激烈 | **止乱**（看清目的、稳住阵脚） |
   | **稳定** | 秩序成型、惯性运转 | **止逸**（别懒散、别把红利当永恒） |
   | **衰退** | 回报走低、旧路径失效 | **止松**（可暂缓动作，但不能松懈观察） |
   | **崩溃** | 结构瓦解、大势已去 | **止逆**（知止止损，不逆势硬扛） |

## 二、七层写法（严格按序，直白狠准）

> 错误示范：只写“今天很累 / 不开心 / 谁让我失望 / 想明白了什么”。这只是浮在表面的情绪宣泄，摸不到真实症结。

### 第 1 层：事实
只写客观发生了什么，**不许解释、不许评价、不许抒情**。
- 示范：“今天他说我变了”“今天看到别人赚钱很快”“本来想回消息后来没回”。
- 作用：先圈定触发点；一上来就讲道理会把真正的症结盖住。

### 第 2 层：第一反应
写事情发生那一刻**最直接的本能念头和情绪**，不是事后反思的“正确答案”。
- 示范：“我当时很想反驳”“我很酸”“我有点怕”“突然很想证明自己”“一下子想逃”。

### 第 3 层：我想得到什么（直白欲望）
逼自己回答：顺着这股劲往前走，我到底想得到什么？**禁止大词（尊严、幸福、意义），必须具体到人和事**。
- 示范：“想让他承认我没错”“想比那个人强”“想让别人高看我”“想保住这段关系”“想确认自己不是失败者”。

### 第 4 层：我在害怕什么（直白恐惧）
写**最丑、最小、最直接、平时说不出口**的那个怕。真正让人缩手的往往在这里。
- 示范：“怕被看不起”“怕我其实没那么厉害”“怕失去他”“怕选错了承认自己很蠢”“怕我其实一直在骗自己”。

### 第 5 层：我给自己找了什么理由（最关键的自洽层）
为了让自己心里舒服，对上面几层做了什么体面包装？**真正的症结通常藏在最会讲的那些“客观理由”后面。**
- 示范：“我不是嫉妒，我只是客观分析”“我不是害怕，我只是在等时机”“我不是不想要，我只是看得更远”“我不是生气，我只是觉得不值得”。

### 第 6 层：最深的症结（唯一主症结）
只允许落到**唯一一句定论**，不要又贪又怕写一堆。
- 示范：“最深的症结是：怕被看轻” / “想证明自己更强” / “怕承担选错的代价”。

### 第 7 层：明天的选择（最小具体动作）
前六层只是“看见”，第七层才开始“选”。必须满足向内 + 向外双重标准：
- 既逼“我”直面内心恐惧，又顺应现实规律、低成本可落地、能换回真实外部反馈。
- 绝不能写成“纯内心顿悟”或“宏大空泛计划”。

## 三、深度校验与防脑补纪律

- **锋利标准**：好的七层剖析不是让用户点头说“说得好对”（那是廉价安慰），而是**让用户第一秒想反驳，却说不出哪里错**。
- **防凭空编造**：所有欲望、恐惧与理由的推断，必须能从用户叙述的细节、矛盾或回避处找到抓手；若用户给的线索极少，明确列出 2 个最可能的症结候选让用户自照，不杜撰不存在的经历。
