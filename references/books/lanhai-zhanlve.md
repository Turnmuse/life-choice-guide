# 《蓝海战略》精华（拥挤市场中的差异化空位局专用）

> 定位：在同质化竞争里寻找未被争夺的价值空间的局——空位怎么创造，而不是要不要更努力。
> 触发信号：问题的核心是拥挤市场里还有没有立足点、差异化如何成立。

## 全书总纲：不要只在存量里抢，去创造没有竞争的价值

金伟灿与莫博涅的命题：竞争激烈、利润被摊薄的"红海"不是唯一战场；通过**价值创新**——同时做到差异化与低成本——可以开创需求、摆脱竞争，进入"蓝海"。蓝海不是技术发明，是价值曲线的重新组合。

## 关键内容精华

### 一、价值创新（核心）

- 蓝海战略的基石是价值创新：**同时**追求差异化与低成本，不是二选一。
- 红海思维把行业现有规则当既定前提，在同一维度上比谁更强；蓝海思维先问：这些规则里哪些根本不该存在。

### 二、四步动作框架（价值曲线怎么改）

对行业的既有要素逐一审视，回答四个问题：

1. 哪些被产业视为理所当然的要素**该剔除**？
2. 哪些要素**该减少**到行业标准之下？
3. 哪些要素**该增加**到行业标准之上？
4. 哪些产业从未提供过的要素**该创造**？

剔除与创造最关键：减少与增加只是改良，剔除与创造才改变价值曲线的形状。个人版转译：找空位不是"别人做什么、我不做什么"，而是把用户付钱买的价值重新组合一遍。

### 三、空位常在默认边界之外

多数人看不见空位，是因为把行业默认的边界当成理所当然：产业之间、战略群体之间、买方链的不同环节、互补品与服务、功能与情感的取舍——这些边界两侧往往藏着未被争夺的价值。

### 四、蓝海也会变红

新空间一旦被验证，追随者涌入，蓝海转红是常态。四步动作是持续动作，价值曲线的领先有保质期——转红之前能不能垒起壁垒，见 `jingzheng-zhanlve.md`。

## 必答问题（用本书时逐条过）

1. 这个市场的价值曲线长什么样？行业默认要素里，哪些其实可以剔除？
2. 用户付钱买的到底是什么价值？这个价值能不能重新组合？
3. 空位是不是藏在行业默认的边界之外？
4. 如果空位存在，为什么还没人做？这个"为什么"是机会还是陷阱？
5. 这个蓝海能保持多久？转红之前够不够垒起壁垒？

## 常见误用

- **把蓝海当"没人做的领域"**：没人做可能因为没有需求——蓝海的前提是价值创新带来的新需求，不是市场空白本身。
- **只增不减**：堆砌新要素是红海式改良；剔除与创造才拉开价值曲线。
- **把蓝海当永久居留权**：没有壁垒的蓝海只是红海的前夜。
