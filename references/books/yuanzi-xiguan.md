# 《原子习惯》精华（执行局专用）

> 定位：方向已明、卡在行动的局。
> 触发信号：问题在执行层，不在选择层。

## 关键章节精华

### 身份认同三层（第 2 章）
- 改变分三层：结果（得到什么）→ 过程（做什么）→ **身份**（相信自己是什么人）。多数人的顺序是反的。
- 最有效的改变不是"我要达成什么"，而是"我要成为哪种人"——每个行动都是给"我是谁"投的一票。
- 对应提问：**他是在"追目标"还是在"换身份"？他的每个今天在给哪种人投票？**

### 行为改变四定律（第 3–12 章）
| 定律 | 养好习惯 | 戒掉坏习惯（反向） |
|---|---|---|
| 1. 显而易见 | 环境设计：把提示放眼前；习惯叠加："做完 X 后我就做 Y" | 让它隐形：把提示移出环境 |
| 2. 有吸引力 | 诱惑绑定：想做的事和该做的事捆绑 | 让它无吸引力：重构对它的看法 |
| 3. 简便易行 | 减少摩擦；**2 分钟规则**：新习惯必须能在两分钟内开始 | 增加摩擦：让坏习惯难启动 |
| 4. 令人满足 | 即时奖励；习惯追踪（不要打断链条） | 让它不满足：问责伙伴/违约成本 |

- **环境 > 动机**："自律"的人只是很少把自己放进诱惑里。改造环境一次，受益每天。

### 平台期与潜能蓄积期（第 1 章）
- 突破前的平台期看起来最像失败——冰在 0 度以下看不出融化，但热量一直在蓄积。多数人就死在这一段。
- 每天进步 1%，一年 37 倍；习惯的复利前期是隐形的。
- 对应提问：**他是方法错了，还是只是还在蓄积期？**（这两个处方向反：前者换方法，后者别动）

### 金发姑娘区（第 15 章）
- 动力的峰值出现在难度适中的任务——太难会焦虑，太易会无聊。坚持不了有时不是意志问题，是任务难度没校准。

### 规则补充
- "不要打断两次"：断一次是意外，断两次是新习惯的开始。补救的标准动作是"当天就做最简版本"。
- 习惯追踪的真正作用是**可见的证据**：让大脑每天看到自己在成为那种人。

## 必答问题（用本书时逐条过）
1. 方向本身确定吗？（不确定就先回选择层，本书不管选方向）
2. 卡在哪一定律：没提示 / 没吸引 / 太麻烦 / 没即时反馈？
3. 环境里最大的摩擦和诱惑分别是什么？能不能只改环境不改人？
4. 新习惯的两分钟版本是什么？
5. 他是方法错了，还是还在潜能蓄积期？

## 常见误用
- 用执行层工具掩盖选择层问题——"坚持不下去"有时是主石头在报警，不是习惯系统坏了；此时回第 5 步道痕，不在本书范围。
- 上来就堆强度（每天一小时健身/学习）——违背 2 分钟规则，必崩。
